# 📊 ASKO Sales Reconciliation & Lost Leads Recovery Tool

> Автоматизированный desktop-инструмент на Python для сквозной сверки CRM/Telegram-лидов с фактическими продажами розничной сети и верификации KPI операторов контакт-центра.

---

## 🎯 Бизнес-задача
В процессах контакт-центра операторы ежедневно фиксируют сделки в закрытом Telegram-канале (30–40 обращений в день, 1000+ в месяц). При ручной сверке отчетов филиалов и утвержденного KPI часть продаж теряется из-за:
- Человеческого фактора при ручном сведении реестров.
- Опечаток в именах операторов в накладных.
- Покупок клиентов по альтернативным номерам.

**Результат внедрения решения:** Полная автоматизация аудита продаж, исключение ручного поиска в учетных системах и возврат до 100% упущенных начислений KPI.

---

## 🚀 Функциональные возможности
- **Универсальный парсинг:** Прямой импорт сырых дампов Telegram (`result.json`) и таблиц (`.xlsx`).
- **Data Normalization Engine:** Очистка и приведение телефонных номеров из любых форматов (`+998`, пробелы, скобки, экспоненциальная запись) к единому 9-значному стандарту.
- **Dynamic File Aggregator:** Автоматическое объединение ежедневных отчетов филиалов компании с разной структурой колонок (`Количество`/`K-BO`, `OPERATOR`/`Unnamed`) в единый массив продаж.
- **Двухуровневая аналитика:**
  - `1_Poteryannye_Prodazhi_Avto.xlsx` — 100% подтвержденные продажи по совпадающим номерам (договор, склад, номенклатура).
  - `2_Na_Proverku_Rukovoditelyu.xlsx` — готовый реестр для РОПа на верификацию первого касания в Битрикс24.
  - `3_Mega_Baza_Prodazh_Mesyats.xlsx` — консолидированный архив всех складов.
- **Multilingual Modern GUI:** Графический интерфейс на `CustomTkinter` с мгновенным переключением языков (**O'zbek / Русский**), индикаторами метрик и встроенной HTML-документацией.
- **Portable Binary:** Сборка в автономный `.exe` файл, готовый к запуску на любом рабочем ПК без необходимости установки Python.
